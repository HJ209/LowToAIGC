# 实验发现汇总

## 实验0：朱雀实测 + 本地困惑度代理验证

同一条第3章网文（约5000字）四个版本，朱雀在线检测 vs 本地困惑度(PPL)：

| 文本 | 朱雀·高置信AI | 朱雀·疑似AI | 朱雀·人类 | 本地PPL |
|---|---|---|---|---|
| 原版（纯AI） | 62.74% | 37.26% | 0% | 16.65 |
| 轻度改写 | 15.74% | 84.26% | 0% | 35.85 |
| 深度改写 | 14.95% | 85.05% | 0% | 47.39 |
| 混排（插真人式段） | 22.31% | 77.69% | 0% | 51.40 |

**结论：**
- 困惑度越低 → 朱雀判"高置信 AI"越狠（原版 PPL 16.65 对应 62.74%）。**PPL 可作为朱雀高置信AI率的免费本地代理**，用于横扫参数、免烧朱雀额度。
- 事后改写能把高置信 AI 从 62.74% 压到 ~15%，但**人类创作始终 0%**：只要是 AI 写的（哪怕模仿人腔、PPL 升高），仍带指纹。混排版插入"AI 模仿的真人段"反而让高置信AI回升到 22%——证明"AI 写的假人味"骗不过朱雀。
- PPL 与朱雀非完全线性（朱雀还看节奏突发性、全文一致性），但大方向一致，足够做相对排序。

## 实验1：采样参数 -> 困惑度（第1层，治标）

生成模型 `Qwen/Qwen2.5-0.5B-Instruct`，打分模型 `Qwen/Qwen2.5-0.5B`，同一写作指令扫 12 组参数：

| temperature | top_p | repetition_penalty | perplexity |
|---|---|---|---|
| 1.3 | 0.95 | 1.2 | **34.66** |
| 1.3 | 0.85 | 1.2 | 25.64 |
| 1.0 | 0.95 | 1.2 | 17.72 |
| 1.3 | 0.95 | 1.0 | 12.73 |
| 1.0 | 0.85 | 1.2 | 11.08 |
| 0.7 | 0.95 | 1.2 | 10.89 |
| 1.0 | 0.95 | 1.0 | 9.85 |
| 0.7 | 0.85 | 1.0 | 7.37 |
| 0.7 | 0.95 | 1.0 | **7.13** |

**结论：**
- `repetition_penalty=1.2` 是最稳的杠杆，几乎在所有温度下都显著抬高困惑度。
- 温度从 0.7→1.3 抬升困惑度，`top_p` 放宽（0.85→0.95）有正向但较弱。
- 最优组（temp1.3 / top_p0.95 / rp1.2）把困惑度从最低的 7.13 抬到 34.66，约 **4.8 倍**。

**重要警告（质量代价）：**
- 0.5B 小模型在高温下生成质量崩坏（掉字、语句不通），见 `generations/`。说明：**调采样参数能抬升困惑度，但在小模型上以牺牲可读性为代价**。
- 推论：可用的降AI管线需要"更强的基座模型 + 适度采样"或"真人语料微调（第2层）"，单靠小模型+高温不可行。

## 实验1b：用 1.5B 本地模型整章改写（`src/rewrite_chapter.py`）

把第3章原文分段（每3段一组，共45组）喂 `Qwen/Qwen2.5-1.5B-Instruct` 改写，
采样 temp1.1/top_p0.95/rp1.2，产物 `ch3_local_rewrite_best.txt`。

- 困惑度：原文 PPL 16.65 -> 改写后 **47.20**（与人工深度改写 47.39 相当，理论上"降AI"有效）。
- **但成品不可用**：1.5B 在 CPU 上无法忠实改写——捏造情节（灵药/吃苹果/室友八卦/整段早晨流水账）、
  混入英文句子、改错人名（赵明->章明、凭空出现陈浩）、泄露元注释（"如果这个是人工智能写的…"）。
- 结论钉死：**"困惑度上去"≠"文章能用"**。小模型(<=1.5B)单独做忠实降AI改写不可行；
  必须靠"更强基座(GPU/API) + 真人语料微调(第2层)"或真人逐段改写。
- 工程坑：fp32 同时载 1.5B+0.5B 会 OOM（8G机），改为先生成、释放后再载0.5B打分；bf16 在CPU上生成极慢，弃用。
